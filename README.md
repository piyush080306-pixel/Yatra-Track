# Hyper-Local-Trust-Network

A Smart Community Management Platform 🏙️

The **Hyper-Local-Trust-Network** is a modern web application built to strengthen trust, safety, and collaboration inside local communities. It connects **residents, security teams, and service providers** through a unified, real-time management system.

It focuses on **secure communication**, **visitor management**, **payment tracking**, **alerts**, and **neighborhood services**, ensuring a safer and more transparent living ecosystem.

---

## 🌟 Key Features

### 🧾 Visitor Management

Real-time visitor updates, gate entries, exit logs, and pre-approved access lists to ensure complete security control.

### 🏘️ Community Posts & Announcements

Stay updated with local notices, building rules, important circulars, events, and community news.

### 💳 Payment & Dues Tracking

Track society maintenance payments with clear status indicators: **Paid**, **Due**, **Overdue**, and **Pending Approvals**.

### 🚨 Security Logs & SOS System

Monitor visitor logs, deliveries, guard activities, and get instant emergency alerts.

### 🔐 Connected Device Monitoring

Track login sessions, detect suspicious sign-ins, and monitor connected devices for safety.

### 🛒 Local Marketplace

A mini-community marketplace to sell, donate, or request items from neighbors.

### 🌙 Dark Mode Support

Smooth theme switching with automatic LocalStorage persistence.

### ⚡ Quick Action Buttons

Instant shortcuts for:
Helpdesk • QR Scan • Home Services • Emergency SOS • Visitor Approval

### 🏊 Amenity Booking & Delivery Pre-Approval

Book amenities such as the clubhouse, gym, pool, etc., and pre-authorize delivery agents for hassle-free access.

### 💬 Responsive UI

A clean, modern interface optimized for mobile, laptop, and tablets.

## 🖥️ Installation & Setup

#### 1️⃣ Clone the repository

```bash
git clone https://github.com/piyush080306-pixel/Hyper-Local-Trust-Network.git
```

#### 2️⃣ Navigate into the folder

```bash
cd Hyper-Local-Trust-Network
```

#### 3️⃣ Run the project

Since this project is fully frontend:

### Option A — Open directly

Open `index.html` in your browser.

### Option B — Run a local server (recommended)

```bash
python3 -m http.server
```

Then visit:
👉 [http://localhost:8000](http://localhost:8000)

## 🚀 Usage Guide

### 🔍 Search & Filters

Use the search bar and tabs to quickly filter visitors, logs, and announcements.

### 📌 Bottom Navigation

Switch between:

* Home
* Payments
* Security
* Marketplace
* Profile

### ⚡ Quick Actions

Approve visitors, open helpdesk, call emergency contacts, or request home services.

### 🌙 Dark Mode

Toggle from the top-right corner — automatically saved in LocalStorage.

### 🏊 Amenity Booking

Use interactive popups to book amenities with time-slot validation.

### 🚚 Delivery Pre-Approval

Approve Swiggy/Zomato/Amazon deliveries ahead of time for smooth entry.

### 🔐 Security Monitoring

See device activity, logins, and alerts in the Security section.
